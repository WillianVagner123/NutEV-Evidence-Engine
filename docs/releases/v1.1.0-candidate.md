# NutEV Reference Engine 1.1.0 — candidate release notes

**Not published. Not a production-acceptance or scientific-validation claim.**

This candidate retains the `nutev-nutmev` distribution and the existing CLI identity.
It adds authenticated project isolation, scoped libraries/review/export services,
first-party source-owner checks, browser context invalidation and exact-SHA
release controls. Legacy unscoped scientific APIs are not available in pilot.

Release hardening includes explicit Python package boundaries, private-file
exclusions for Docker, built-artifact inspection, installation outside the source
checkout, a disposable real-container gate and snapshot metadata restoration.
No historical article ID, query, scoring/taxonomy rule, human decision or A2
binding is changed by the publication-preparation work.

The wheel/sdist are Python-library/CLI artifacts. Website deployment uses the
reviewed source commit and Dockerfile. Access is administratively provisioned;
public signup is not part of the supported release. Scientific incremental
benefit remains unproven under the existing validation status; ranking is not
eligibility, quality, certainty or clinical recommendation.

The v1.0.0 tag/archive remains immutable. Version 1.1.0 does not inherit its
version-specific DOI. A new publication date, release tag and archive identifier
will only be stated after the corresponding service operation is verified.

See `docs/PUBLICATION_READINESS.md`, `docs/SYSTEM_CLOSEOUT_MASTER.md` and
`docs/FINAL_SYSTEM_ACCEPTANCE.md` for actual scope and unresolved gates.
