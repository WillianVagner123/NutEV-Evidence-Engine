## Summary

NutEV 1.1.0 closes the production hardening cycle for the multi-user web product while preserving the existing `nutev-nutmev` Python distribution and CLI identity.

The release adds authenticated workspace/project isolation, scoped library/review/export services, first-party source-owner checks, browser context invalidation, fail-closed private surfaces and exact-SHA deployment controls.

Release hardening also includes explicit Python package boundaries, Docker private-file exclusions, built-artifact inspection, installation outside the source checkout, disposable real-container validation and recovery metadata verification.
