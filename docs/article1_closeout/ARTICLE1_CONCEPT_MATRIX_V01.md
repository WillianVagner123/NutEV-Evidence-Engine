## Distinções obrigatórias

Não fundir automaticamente:

- literacia ≠ habilidade;
- habilidade ≠ agência;
- agência ≠ eating competence;
- competência do paciente ≠ competência profissional;
- documento normativo ≠ estudo sobre documento normativo;
- contexto social ≠ ambiente alimentar;
- monitoring de implementação ≠ monitoramento nutricional individual.

## Relações provisórias

Podem ser usadas como hipóteses de codificação, nunca como afirmações das fontes sem evidência textual:

- avaliação → prescrição;
- avaliação → aconselhamento;
- literacia → habilidade → agência;
- ambiente → comportamento;
- competência profissional → implementação;
- monitoramento → adaptação.
